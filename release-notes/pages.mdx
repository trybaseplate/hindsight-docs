Pages is ready for an internal preview: create an HTML output with the Hindsight agent, then revisit it from a dedicated library.

## What's included

- **Saved pages:** Browse reports, deal briefs, meeting prep, battlecards, and guides with titles, summaries, and creation dates.
- **Workspace links and downloads:** Open a saved page, share its link with colleagues in the same workspace, or download the HTML file.
- **Reusable templates:** Preview Hindsight layouts and workspace uploads in **Pages → Templates**.
- **Custom layouts:** Upload an HTML template up to 2 MB, add usage notes, preview it, and save it for your workspace.
- **Skill preferences:** Set a preferred page template on supported skills, while keeping research instructions separate from presentation.

## Try it

Open Chat and ask:

> Create an HTML page summarizing why we lost competitive deals last quarter. Include supporting deal examples, the main objections, and recommended actions for sales.

Open the returned link, then find the saved output in **Pages**.

## Internal preview notes

- Explicitly request an **HTML page**. Ordinary report and brief requests still default to Markdown.
- Page links require Hindsight sign-in and access to the same workspace; they are not public publishing links.
- The library filter applies to the current page of results.
- Uploaded templates remove custom JavaScript and external resources. Preview before saving.
- A template supplies layout guidance, not factual evidence.

During the preview, share the prompt, page link, and what you expected when reporting a problem. Feedback on evidence quality, layout, template reuse, and downloads will help us prepare the wider rollout.

---
title: "Pages"
description: "Create, revisit, and share HTML reports, deal briefs, and guides in your workspace."
---

Pages gives the HTML outputs you create with Hindsight a shared home. Use it for a win/loss report, a deal brief, meeting prep, a battlecard, or an enablement guide.

## Create your first page

1. Open **Chat** and describe the work you need, including the deals, competitor, or timeframe to research.
2. Explicitly ask for an **HTML page**. For example:

   > Create an HTML page summarizing why we lost competitive deals last quarter. Include supporting deal examples, the main objections, and recommended actions for sales.

3. Review the findings and open the page link returned by the agent.
4. Open **Pages** to revisit the saved output later.

<Note>
A request for a report or brief alone returns a Markdown response by default. Ask for an HTML page when you want a saved Page. A template preference alone does not change the output format.
</Note>

## Find and share saved pages

Open **Pages** to browse saved outputs. Each card includes a title, summary, creation date, and download action. The filter searches titles and summaries on the current page of results; use **Previous** and **Next** to browse additional results.

Open a page and copy its URL to share it with colleagues in the same workspace. Recipients must sign in to Hindsight and have access to that workspace. Page links do not publish the content publicly.

Choose **Download HTML** in the page viewer, or the download icon in the library, to save an HTML file. Downloading does not send or publish it.

## Reuse a template

In **Pages → Templates**, preview Hindsight templates and templates uploaded by your workspace. Ask the agent to use a named template when creating an HTML page, or describe a custom layout.

Templates guide presentation; they are separate from a skill's research instructions. Several skills can reuse the same template, and a request can choose a different layout.

### Upload a workspace template

1. Select **Upload template** in Pages.
2. Choose an HTML file up to 2 MB. Embed styles and images in the file.
3. Add a name, description, and usage notes explaining what the agent should preserve or adapt.
4. Select **Preview** and check the result.
5. Select **Save template**. The template is shared with your workspace.

<Note>
Custom JavaScript and external resources are removed from uploaded templates. Preview the supported result before saving. Example content in a template is a layout reference, not evidence for a new report.
</Note>

### Set a skill's preferred template

Where a skill exposes **Preferred page template**, select a layout to use when that skill produces an explicitly requested HTML page. The skill owner or a workspace admin/manager can change this preference. Select **No preference — choose for the task** to let the agent choose. An explicit template choice in a request overrides the preference.

## Try these prompts

- “Create an HTML page with a meeting prep brief for this deal: buyer priorities, open questions, competitive risks, and supporting evidence.”
- “Create an HTML battlecard for this competitor using our recent deal evidence. Include objections and suggested responses.”
- “Create an HTML page for a product review of feature gaps mentioned in lost deals this quarter. Cite the supporting deals.”

Review the supporting evidence and recommendations before using a page to guide a decision or sharing its downloaded content.
